# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Команды

- Разработка: `npm run dev`
- Сборка (проверка типов и Vite): `npm run build`
- Линт: `npm run lint`
- Все тесты: `npm test` (то же, что `npx vitest run`)
- Один тест: `npx vitest run src/ui/App.test.tsx` (или `npx vitest run -t "часть названия"`)
- Сквозные тесты: `npm run e2e` (Playwright, установленный Chrome, 1180×820). Сам собирает приложение и запускает `vite preview` на порту 5301: у каждого порта своя база браузера, партии на 5199 не затрагиваются. Сервис-воркер есть только в сборке, не в `npm run dev`.

В `src/test-setup.ts` подменяется `localStorage`: глобальный `localStorage` в Node 25 затеняет jsdom и без флага не работает.

Полный дизайн: [docs/superpowers/specs/2026-11-05-ti4-planner-design.md](docs/superpowers/specs/2026-11-05-ti4-planner-design.md). Сверка игровых данных с источниками: [docs/data-verification.md](docs/data-verification.md).

## Продукт

Лёгкий планировщик партии в Twilight Imperium 4 на веб-технологиях, локальное PWA с упором на планшет в альбомной ориентации. Игрок вручную строит план по раундам, а приложение считает ресурсы, жетоны и лимиты.

**Главное требование: инструмент должен оставаться лёгким.** Пользователь уже отклонил ветки планов, таблицы сравнения и автоматизацию правил как избыточные. Новые функции предлагай в самом простом виде и не добавляй сложность без запроса.

## Архитектура

Зависимости идут в одну сторону:

- `scripts/`: сборщик игровых данных и картинок юнитов, генератор иконок приложения и их тесты; в приложение не входит.
- `src/domain`: чистый TypeScript без React и браузерных API, включая единый расчёт состояния.
- `src/storage`: IndexedDB, экспорт и импорт файла.
- `src/ui`: экраны, карта, жесты на pointer-событиях, i18n.

Состояние партии не хранится, а всегда вычисляется повторением записей плана. «Сейчас» считается только по выполненным записям, «прогноз» по выполненным и запланированным. Каждый план на вкладке хранит собственную копию записей.

## Интерфейс

- Меню из двух экранов, «Партия» и «План и карта», гексами в колонке слева, внизу кнопка экспорта; пока партия не создана, меню нет. Игроки, дополнения и язык живут на «Партии». План и карта на одном экране, сборка карты включается кнопкой «Собрать карту».
- Нажатие на систему открывает большой гекс (сцену) для расстановки, боя и покупок. Fracture ставится по номеру места игрока.
- Игроки, легенда, улучшения и Thunder's Edge выезжают из вертикальных шторок по бокам карты, без кнопок закрытия. Левые размывают фон и закрываются нажатием вне себя. Правые выезжают из-под панели плана, не мешают карте и закрываются только повторным нажатием на язычок. Карта лежит в глубине: тень по всему её краю, шторка отбрасывает на неё свою, между шторкой и планом тени нет. Над картой висят только действия с ней, «прогноз/сейчас» стоит справа от раундов. Крестик везде один: `HexRemove`.
- Цвет края вкладок и шторок: голубой значит не выбрано, зелёный значит выбрано, как у выполненных действий.
- Модалы на весь экран размывают фон, это выключается на «Партии» (`localStorage`, `ti4.blur`).
- Кнопка экспорта с иконкой (`ExportReminder`) стоит внизу колонки меню и просит постоянное хранение; когда нужна новая копия, она отмечена золотым. Время последней файловой копии лежит в `localStorage` (`ti4.lastExportAt`). Отметка появляется, если копии не было никогда, если она старше недели при постоянном хранении или старше суток без него. Экспорт её снимает.

## Правила домена

- Предупреждения ничего не запрещают: способности и технологии могут менять правила. Способности и карты учитываются ручными правками с подписью.
- Дополнения выбираются независимо: Thunder's Edge требует базовую игру, но не Prophecy of Kings.
- Набор стратегических карт зависит от дополнений. Thunder's Edge заменяет Construction и Warfare.
- Стрелки на карте используются только для перемещения в тактическом действии.
- Лидеры и мехи существуют только с Prophecy of Kings, даже у фракций Thunder's Edge (правила TE). Thunder's Edge заменяет часть карт: у Jol-Nar Ta Zern на Agnlan Oln; что на что, задано в `scripts/build-data.ts`. Каждый такой компонент подписан дополнением.
- Системы открытого Излома лежат в `game.fracture.tiles` под обычными ключами слотов, поэтому ходы, расчёт и большой гекс работают с ними как с картой. Они не смежны с тайлами карты рядом: такой шаг маршрута рисуется разрывом.

## Данные и язык

- Игровые данные берутся только из публичных источников и хранятся как пакеты с указанием происхождения. Источники и правила сборки описаны в спецификации.
- Числа из прототипов частично заполнены по памяти, не переноси их в приложение.
- Не копируй арт из игры и источников: лицензия AsyncTI4 его исключает, а у KeeganW/ti4 лицензии нет. Описания карт пересказывай своими словами.
- Интерфейс идёт через i18n: русский и английский, с выбором языка. Игровые названия остаются на английском.
