# Журнал сверки игровых данных

Данные собраны командой `npx tsx scripts/build-data.ts` из `AsyncTI4/TI4_map_generator_bot`, коммит `9eee64a3b13fc698b3ee174590dde40e005c0dfe` (2026-11-05). Версия данных: `2026-11-05-9eee64a`. Все проверки выполнены 2026-11-05.

Статусы:
- **подтверждено**: значение совпало с источником, независимым от основного, или с текстом правил;
- **один источник**: значение есть только в основном источнике, независимой сверки нет;
- **не подтверждено**: факт найти не удалось, предположение в данные не записано.

На 3, 4 и 5 игроков два шаблона, `Game.layout` (`standard` или `hyperlanes`) выбирает один из них. С Prophecy of Kings доступны оба варианта; без него гиперпутей нет и вариант с ними показан недоступным (нужен PoK). На 5 игроков с PoK по умолчанию стоит вариант с гиперпутями, это раскладка правил; на остальные числа по умолчанию `standard`. Для 6, 7 и 8 игроков вариант один. Альтернативные раскладки PoK на 7 и 8 игроков и шаблоны источника `7pHyperlanes`, `8pHyperlanes` не используются: в них помещается только 35 и 40 тайлов, а стандартная раздача даёт 47 и 52. Сыграть альтернативную раскладку можно на тех же 61 клетке, вводя тайлы вручную.

Домашние слоты (`MapTemplate.homes`, `seatSlots`): места по порядку, место 1 вверху, дальше по часовой стрелке. Это позиции домов в шаблонах `MAP_3`-`MAP_8` Milty Draft, потому что пользователь драфтит там и строка Milty ставит дома именно туда. Относительно прежнего расчёта (ближайший слот внешнего кольца к равномерному углу) изменились 4 игрока (`3,-3` вместо `3,-2` и `-3,3` вместо `-3,2`), 5 (дома в `3,-3`, `3,0`, `-3,3`, `-3,0`) и 7 игроков (пять мест из семи); 3, 6 и 8 игроков совпали. Дома не стоят в шаблоне фиксированными тайлами: место игрока ставит Task 15.

Смена раскладки (`changeLayout`): тайлы остаются в слотах, которые есть в обеих раскладках; фиксированные тайлы старой раскладки, которые игрок не менял (центр, гиперпути), уходят вместе с ней; гиперпути новой раскладки ставятся всегда и вытесняют тайл игрока на своём слоте (центр ставится только в пустой слот). Тайлы в слотах, которых нет у новой раскладки, снимаются. Переключатель на экране «Партия» просит подтверждения, только если что-то снимается, и называет число тайлов (`tilesLostByLayout`). Раскладку определяет и вставка строки Milty: есть гиперпуть, значит вариант с гиперпутями, иначе обычный.

Линии гиперпутей: `TileDef.lanes` хранит пары граней из `data/hyperlanes.properties` AsyncTI4 (грань 0 вверху, нумерация по часовой), для 83A-91B, 18 тайлов. Сборщик сверяет, что каждая повёрнутая строка источника (`83a60`..`83a300`) совпадает с базовой, сдвинутой на нужное число граней по часовой, так что направление поворота `@n` подтверждено по данным всех 18 тайлов, а не по одному примеру. Совпадение базовой ориентации с печатным тайлом не проверено. Для 119A-124A данных нет, см. выше.

Поворот `@n` означает n шагов по 60 градусов по часовой стрелке. Подтверждено `data/hyperlanes.properties`: каждый шаг сдвигает номера граней на 1, а `positions/tileAdjacencies.properties` нумерует грани по часовой от севера.

Thunder's Edge заменяет Mecatol Rex на тайл с символом легендарной планеты (TE). Соответствие этого тайла номеру 112 следует из источника и KW. `loadPack` подставляет `112` в центр всех шаблонов, если TE включён. Если Thunder's Edge включают в начатой партии, `addExpansion` одним шагом отмены меняет центр 18 на 112 и переносит записи с планеты `mr` на `mrte` (контроль, доки, посадки, оплату и подбор войск во всех планах).

### Направление поворота гиперпутей

`data/hyperlanes.properties` AsyncTI4: у `83b` связи граней 0-2, 0-3, 3-5; у `83b60` связи 1-3, 1-4, 4-0. Каждые 60 градусов сдвигают номера граней на +1 (так же у `83a`: 1-4, затем 2-5), а грани по `tileAdjacencies.properties` нумеруются по часовой от севера. Значит шаг поворота это 60 градусов по часовой, как `@n` в приложении. Milty рисует `rotate(n*60deg)` в CSS, это тоже по часовой. Совпадение базовой ориентации тайла в картинке Milty и в AsyncTI4 прямо не проверено: сравнить один и тот же тайл с разным поворотом в обоих источниках нельзя, а в 5-игроковой раскладке совпавшие слоты имеют поворот 0.
