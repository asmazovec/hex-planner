# Планировщик партии TI4: план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Лёгкое локальное PWA для планшета: карта по номерам тайлов, несколько планов партии на вкладках и автоучёт ресурсов, жетонов и лимитов.

**Architecture:** Зависимости идут в одну сторону: сборщик данных → пакеты → домен → хранилище → интерфейс. Состояние не хранится, а вычисляется функцией `project` из записей плана. Интерфейс не содержит игровых расчётов.

**Tech Stack:** React, TypeScript, Vite, Vitest, Testing Library, Playwright, zustand, idb, zod, i18next, vite-plugin-pwa. Берутся текущие стабильные версии.

**Spec:** [docs/superpowers/specs/2026-11-05-ti4-planner-design.md](../specs/2026-11-05-ti4-planner-design.md)

## Global Constraints

- Основной режим: «планшет в альбомной ориентации». Проверочный размер: 1180×820.
- Интерфейс через i18n: русский и английский, с выбором языка. «Игровые названия остаются на английском».
- «Предупреждения ничего не запрещают».
- «Всё, что делается перетаскиванием, должно быть доступно и нажатиями».
- Жесты только на pointer-событиях. Одним пальцем тянется стрелка или запись, двумя карта перемещается и масштабируется.
- `src/domain` без React и браузерных API.
- Арт из игры и источников не копируется. Описания карт пересказываются своими словами. Числа из прототипов в приложение не переносятся.
- Сеть во время игры не нужна.
- Новую сложность без запроса не добавлять: инструмент должен оставаться лёгким.

## Review Focus

- Удаление или перенос записи, от которой зависят более поздние (перемещение уже ушедших кораблей): расчёт не падает, счётчики не уходят в минус, остаётся понятное предупреждение. Тест в Task 3.
- Оплата устарела после переноса записи (планета уже истощена раньше по плану): появляется предупреждение, оплата молча не меняется. Тест в Task 4.
- Импорт файла новее текущей схемы или повреждённого файла: понятный отказ, существующие партии не меняются. Тест в Task 5.
- `pointercancel` или второй палец во время вытягивания стрелки: незавершённая стрелка исчезает, запись не создаётся. Тест в Task 10.
- Попытка удалить единственный план и пустое название плана: последний план удалить нельзя, пустое название заменяется значением по умолчанию. Тест в Task 6.

type EntryStatus = 'planned' | 'done' | 'cancelled';
type Phase = 'strategy' | 'action' | 'status' | 'agenda';
interface Payment { planets: string[]; tradeGoods: number; }
type EntryBody =
  | { type: 'tactical'; systemId: string | null; moves: { from: string; units: UnitCounts }[];
      landings: { planetId: string; units: UnitCounts }[]; production: UnitCounts; payment: Payment }
  | { type: 'strategic' } | { type: 'secondary' } | { type: 'component'; note: string } | { type: 'pass' }
  | { type: 'expedition'; sliceId: string | null; payment: Payment }
  | { type: 'adjustment'; label: string; delta: AdjustmentDelta }
  | { type: 'statusTokens'; tactic: number; fleet: number; strategy: number };
interface AdjustmentDelta { tradeGoods?: number; tactic?: number; fleet?: number; strategy?: number;
  vp?: number; units?: { systemId: string; units: UnitCounts }; }
type Entry = EntryBody & { id: string; phase: Phase; status: EntryStatus };
interface Round { number: number; strategyCard: number | null; backupCard: number | null; entries: Entry[]; }
interface Plan { id: string; name: string; rounds: Round[]; }
interface Game { id: string; schemaVersion: number; dataVersion: string; expansions: ExpansionId[];
  playerCount: number; faction: string; map: Record<string, string>;
  opponents: { faction: string; vp: number }[]; enemyUnits: Record<string, UnitCounts>;
  planetControl: Record<string, 'me' | 'enemy'>;
  expedition: { slices: Record<string, 'me' | 'other' | null>; thundersEdgeSystem: string | null };
  fracture: { active: boolean; ingress: string[] }; plans: Plan[]; activePlanId: string; }
interface GameState { systems: Record<string, UnitCounts>; ground: Record<string, UnitCounts>;
  exhausted: string[]; control: Record<string, 'me' | 'enemy'>; tokensOnMap: string[];
  tradeGoods: number; tactic: number; fleet: number; strategy: number; vp: number; }
type WarningCode = 'shortResources' | 'shortInfluence' | 'shortTradeGoods' | 'planetExhausted'
  | 'capacityGroup' | 'capacitySystem' | 'fleetPool' | 'unitsMissing';
interface Warning { code: WarningCode; params: Record<string, string | number>; }
type Projection = { state: GameState; warningsByEntry: Record<string, Warning[]> };
