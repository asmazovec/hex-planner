Прототипы Фазы 2

Пункты плана, которые меняют вид страниц. На каждой странице «Сейчас» и «Предлагаю»; где нужен выбор, варианты с кодами. Панели собраны из настоящих классов приложения в ширину планшета; шаги и переключатели нажимаются. Ответ — одним списком, например: «1Г, 2А, 3А, 4Б, 5А, 6А, 7Б, 8А, 9А, 10–25 да, 26 да».
