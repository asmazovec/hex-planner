# Разметка Фазы 2: формат TODO

План Фазы 2 записан в коде, комментарием рядом с проблемой. `npm run plan:todos` собирает их в `docs/phase2/plan.md` (по потокам, волнам, типам, правилам) и `docs/phase2/todos.json`.

## Формат

Одна строка, любой синтаксис комментария (`//`, `/* */`, `{/* */}` в JSX, `<!-- -->` в Markdown, `#` в YAML):

```
// TODO(P2-017) #ws:transport #type:check #rule:95.3 #test:095-transport #size:s #pickup #token — Подбор не проверяет жетон в системе подбора
```

| Тег | Сколько | Значение |
|---|---|---|
| `TODO(P2-NNN)` | 1 | Номер, уникальный. Диапазоны ниже |
| `#ws:<id>` | 1, обязательно | Поток из `scripts/todo-plan.workstreams.ts` |
| `#type:<t>` | 1, обязательно | `bug`, `check`, `model`, `arch`, `dup`, `dead`, `ui`, `vocab`, `data`, `doc` |
| `#rule:<LRR>` | любое | Номер правила как в названии теста, пробелы заменены дефисом: `95.3`, `41-note-6`, `expedition-4.5`. Тег покрывает и вложенные пункты: `16.3` покрывает `16.3.3` |
| `#test:<stem>` | любое | Файл теста правил без `.test.ts`: `095-transport` |
| `#dep:P2-NNN` | любое | Что должно быть сделано раньше |
| `#needs:decision` / `#needs:prototype` | по надобности | Нужно решение пользователя / прототип страницы на утверждение |
| `#size:s/m/l` | 1 | Оценка: s до часа, m до дня, l больше. По умолчанию m |
| `#layer:<x>` | редко | Слой; по умолчанию из пути |
| `#<слово>` | любое | Свободные теги для поиска: `#rivals`, `#capacity`, `#warning-channel`, `#duplicate-of-domain` … |

После тегов ` — ` и короткий текст: в чём проблема **в этом месте кода** и что сделать. Одна проблема — один TODO; если она видна в нескольких местах, у главного места полный TODO, у остальных свои номера с `#dep:` на главный.

Комментарий ставится на строку над проблемным кодом (функцией, веткой, JSX-элементом, CSS-правилом). Код не меняется.
