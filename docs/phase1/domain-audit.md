# Ревизия бизнес-логики (src/domain)

## 1. Чистота и отделение

Что в порядке:

- В `src/domain` нет React, DOM, `localStorage`, IndexedDB (проверено поиском по импортам и глобалам).
- Состояние не хранится, а выводится повтором записей (`project.ts:591` `replay`). Функции принимают `Game`, `Plan`, `DataPack` и возвращают новые данные; `structuredClone` перед пробными прогонами (`project.ts:321`, `403`).
- Предупреждения ничего не запрещают, как требует CLAUDE.md.

## 2. Расхождения с правилами

Полный разбор по первопричинам: [rules-tests.md](rules-tests.md). Двадцать ошибок расчёта (B1-B20), среди них: фаза статуса применяется только в начале следующего раунда (`project.ts:603-607`); маршруты не видят действий соперников; `forToken` не пересчитывается после смены карты; флот и вместимость проверяются после потерь в бою; у строений нет владельца; дом Creuss в одном шаге от любой системы.

## 3. Словарь игры под Vale

Запуск: `npm run lint:terms` (Vale 3.25.1 из `@vvago/vale`). Проверяются комментарии `.ts/.tsx`, Markdown (`CLAUDE.md`, `docs/data-verification.md`) и значения `src/i18n/*.json` (view `I18n`, ключи не проверяются).

| Стиль | Уровень | Что фиксирует | Источник |
|---|---|---|---|
| `TI4.Terms` | warning | английские термины: command token, tactic pool, strategic action, strategy card, tactical action, space dock, war sun, ground forces, hyperlane, wormhole, gravity rift, asteroid field, reinforcements, ready, trade goods и др. | LRR, номер раздела в комментарии каждой строки |
| `TI4.Names` | error | Thunder's Edge, Prophecy of Kings, Mecatol Rex в своём написании | — |
| `Vale.Terms` + словарь `TI4` | error | регистр собственных имён (фракции, Mecatol Rex, дополнения) | данные пакетов |
| `TI4Ru.Terms` | warning | жетон приказа, тактический/стратегический резерв, резерв флота, база, наземные войска, второстепенная способность, товары, Продукция, снабжение, места на борту, значение полёта | русский Rules Reference Hobby World 2021; «Продукция» и «товары» из CLAUDE.md |
| `TI4Ru.EnglishNames` | error | игровые названия не транслитерируются (Мекатол Рекс, Хакан, …) | CLAUDE.md |

Что Vale нашёл сейчас (64 предупреждения, 2 ошибки):

- `ru.json`: «Мекатол Рекс» (строка 538, ошибка); «жетон команд/командования» вместо «жетон приказа» (7 мест); «космодок» вместо «база» (5); «вторичное» вместо «второстепенное» (2); «наземная единица», «наземные юниты» вместо «наземные войска»; «вместимость» вместо «места на борту» (3); «жетон тактики/стратегии» в разных формах (8).
- `en.json`: «ground unit(s)» вместо «ground forces» (2).
- Комментарии кода: «ground units» (23 места в домене и UI), «strategy action» (`strategy.ts:42`).
- `CLAUDE.md`, `docs/data-verification.md`: «вместимость», «вторичное», «жетон команд», «пул флота».

Решение для вас (до Фазы 2): русские термины Hobby World длиннее привычных в интерфейсе. Например, «жетон приказа из тактического резерва» вместо «жетон тактики». Если короткая форма в интерфейсе желательна, её нужно явно разрешить в `TI4Ru/Terms.yml` (одна строка), иначе Фаза 2 заменит её на официальную.
