# Фаза 1: ревизия

Три части, каждая в своём файле:

1. [domain-audit.md](domain-audit.md): чистота бизнес-логики, словарь игры под Vale.
2. [rules-tests.md](rules-tests.md): тесты правил 1 к 1 с Rules Reference, что падает и почему.
3. [ui-audit.md](ui-audit.md): каталоги, контейнеры визуального языка, отклонения, вложенность, логика в UI, задачи Фазы 2.

Источник правил: база знаний RAG, `ti4/tirules2/rules-reference/*.md` (английский LRR, номера разделов) и `TI07_Rules_Reference_RU_2021` (русская редакция Hobby World, из неё русские термины).

- `package.json`: devDependency `@vvago/vale` (бинарник Vale 3.25.1) и скрипт `npm run lint:terms`.
